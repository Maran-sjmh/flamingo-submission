# AI assistance and source-data disclosure

AI assistants, including OpenAI ChatGPT/Codex and Anthropic Claude, supported software implementation, interface/code drafts, documentation, debugging and organization of the project. The team supplied requirements and coordinated integration. Use of an assistant does not independently validate scientific interpretation.

## Runtime AI

The deployed research guide uses the pretrained BAAI BGE-small-en-v1.5 embedding model through Cloudflare Workers AI and Vectorize for semantic retrieval. Keyword retrieval and rank fusion complement the embeddings. Returned evidence text and investigation destinations resolve to the canonical source snapshot.

The public guide requests evidence-only retrieval. Public OpenAI/Groq text generation remains disabled; the backend has no deployed OpenAI API key at the recorded security check. A separately labeled historical private model evaluation is not a live public generator.

## Code, data and illustrations

The original scientific evidence is from NASA sources. AI helped build extraction/organization/search software; it did not create missing NASA measurements. Embeddings are derived machine representations, not additional experiments. Source rows, quotations, identifiers and hashes retain their recorded provenance.

The Learn habitats, procedural textures and flame drawing are illustrations generated by AI-assisted code. Their views carry visible AI-assisted illustration labels. They are not validated physics simulations, operational procedures, or approved spacecraft designs. The flamingo vector mark is an AI-assisted code-generated project symbol, independent of NASA branding.

Original NASA photographs, figure sequences, PDFs and footage are retained with their source credits and are not described as AI-generated media. The project does not claim to have generated NASA logos or mission patches. The team reports that its 30-second video is team-produced and some slide images are AI-generated. Those slide images require visible AI-generated labels; the website disclosure cannot verify the external assets or their labels.
