# Contributing

This repository is the versioned public submission snapshot. The [working repository](https://github.com/Maran-sjmh/flamingo) is the primary location for ongoing team integration. Issues here can report reproducibility problems or request clarification of the delivery.

Keep authored product content, code comments and project documentation in English. Preserve original NASA source strings, citation identities, media and scientific qualifiers. A source correction requires explicit provenance review; a visual change must not silently rewrite evidence.

Before proposing changes, run the application tests, 54 Worker tests, build and repository audit described in the README. Changes to research reconstruction should also pass the offline snapshot audit, store rebuild and corpus equality check in a fresh checkout.

Do not commit model keys, environment secrets, provider ledgers, dependency folders, generated databases or vector caches. Do not enable public paid generation, broaden CORS or deploy into the team's existing account as part of an unrelated contribution.

Report validation honestly: source integrity, retrieval relevance, browser interaction, scientific interpretation and user impact are separate questions. Record future work as future work.
